Deep Model Engine

Deep Mode is real local inference. On iPhone, ShortForge now uses a lightweight neural semantic model on CPU/WASM and avoids the heavier WebGPU planner that can restart Safari. Desktop-class browsers can still use the larger instruction planner. The model never directly mutates the page; ShortForge validates every action first.
iPhone model: Xenova/all-MiniLM-L6-v2 (quantized, about 23 MB). Desktop planner: onnx-community/SmolLM2-135M-Instruct-ONNX-MHA.
iPhone Safe AI intentionally avoids WebGPU for model loading. Model files are cached by the browser after the first successful load.
No API key is stored in this page. The existing provider interface remains available for a future secure server-side model if you ever want a stronger cloud model.
